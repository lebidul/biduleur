# Instructions d'utilisation

Suivez ces étapes pour utiliser le projet :

---

### 📦 **Prérequis**
- Assurez-vous d'avoir **Python 3** installé sur votre machine.
- Installez les dépendances nécessaires avec la commande suivante :

```bash
pip install -r requirements.txt
```

---

### 📂 **Préparation des fichiers**
Placez **tous les fichiers PDF à traiter** dans le dossier :
```
pdf_a_traiter/
```

---

### ⚙️ **Exécution du script**
Lancez le script principal avec la commande :
```bash
python3 main.py
```

---

### 📤 **Récupération des résultats**
- Le fichier de sortie **`output.sql`** sera généré dans le dossier :
```
csv/
```

---

### 🗃️ **Importation dans la base de données**
Importez le fichier **`output.sql`** dans votre base de données pour finaliser le processus.

---

### 📝 **Personnalisation du prompt**
Le fichier **`prompt_mistral.txt`** contient le prompt utilisé par le script.
**Modifiez-le** selon vos besoins ou vos spécificités.

---
